# 从这里开始｜DevAgent v4.2.0完整教材与练习包

日期：2026-09-18。**这是34课完整教材的实际修订包，不是v4.1的优化方案或章节模板。** 原生Agent、LangChain/LangGraph、RAG、Java主线和320小时预算保留；本轮改的是学习目的、文件指向、实验对象和Codex协作方式。

## 1. 先打开什么

解压完整ZIP，双击同一目录的 **00-打开教材.html**。无需启动网站或联网；独立HTML只用于阅读，运行练习需要完整包。

第一次先点[**L00：本课目的与文件导航**](lessons/L00/00-本课目的与文件导航.md)。以后每课都先读自己的00页，不必先通读根目录所有材料。

## 2. 分清两个根目录

**教材根目录**是本ZIP解压后的`devagent-course-v4.2/`，包含`00-打开教材.html`、`lessons/`和`tools/`。这里保存只读基准材料，不当作你的应用项目。

**学习项目根目录**是你自己的`devagent-lab/`，包含`devagent/`、`tests/`、`docs/course/`。教材的副本放在`docs/course/`；个人实验放在`.local/`；自己的记录放在`docs/learning-records/`。

除下面初始化代码块外，各课实验都从**学习项目根目录**执行，不再让你猜当前终端在哪一层。

## 3. 没有学习项目时：先创建，不要求立即完成L00实现

在**教材根目录**打开终端，逐条运行：

```text
python tools/course.py doctor
python tools/course.py init ../devagent-lab
cd ../devagent-lab
git init
```

`doctor`不调用模型；框架缺失不阻塞L00。Python应满足3.12及以上基线，具体准备见[环境与Python过桥](02-环境与Python过桥.md)。`init`只接受不存在的目标目录；已有同名目录时拒绝覆盖，请使用你的既有项目或另取新目录名。

初始化会复制L00起始骨架，**不是替你完成应用**。项目`devagent/app.py::run_task`尚未实现，初始测试出现`NotImplementedError`是待实现状态。暂时只学概念时，可以先不运行项目测试。

现在终端已经在学习项目根目录，做第一份概念副本：

```text
python docs/course/tools/prepare_example.py L00 --project .
python .local/concepts/L00/00-example.py
```

本次真正运行的是`.local/concepts/L00/00-example.py`；需要改输入时只改该副本。原始基准在`docs/course/lessons/L00/00-example.py`。它与项目`devagent/app.py`不是同一个文件。

“整数42”有独立探针，不需要猜在哪里改：

```text
python docs/course/tools/probe_l00.py --project . --task-json 42
```

先预测再看结果；详细对象与观察字段见[L00实验](lessons/L00/03-实验与排错.md)。探针如实报告当前概念代码的异常，不假装它已经返回规范拒绝。

## 4. 已有学习项目时：不要重新init

保留源码、Git历史和个人记录。将原`docs/course/`单独备份，再把本完整教材目录的内容更新到`docs/course/`。不要覆盖`devagent/`、`tests/`、`java-task-service/`、`.local/`或`docs/learning-records/`。

本包不会自动迁移或修改你的实际仓库。已经学过的课不用重新生成全部应用；先读该课00页，让Codex按02的`REVIEW_ONLY`模式核对目标与现有实现，再补实际缺口。已有概念副本不会被准备工具覆盖。

## 5. 每课六份文件的用途

| 文件（均在当前课lessons/课号/下） | 你为什么打开它 |
| --- | --- |
| 00-本课目的与文件导航.md | 当前工程缺口、前置、变化目标、先看哪里、哪些文件存在 |
| 01-教程.md | 带着“读这一段解决什么问题”学习机制和反例 |
| 02-交给AI.md | 唯一必附课程指令；选择只分析、实施或复核，并提供当前源码 |
| 03-实验与排错.md | 创建副本、指定改动位置、运行命令和观察证据 |
| 05-过关卡与代码地图.md | 在概念例子或已生成源码中定位入口、分支和状态 |
| 04-复习与迁移答案.md | 独立尝试后再核对，不默认交给Codex |

**顺序：00明确目的 → 01学习 → 03的概念练习 → 02分析/实施 → 03项目案例和05定位 → 04核对。** 不需要为了文件编号按04先于05阅读。

## 6. 给Codex什么：不需要你先猜文件名

在Codex中打开你的学习项目，附`docs/course/lessons/L00/02-交给AI.md`，发送：

```text
只分析本课文档意图和当前源码，不修改代码。
解释本课为什么学、要改变什么行为、哪些边界不能改变。
请先读取仓库，给出真实文件/函数或配置块和原文锚点；不存在则标待生成。
最后告诉我应该先看哪几段代码，怎样判断目前实现是否符合意图。
```

需要开始实现时再发送“按本课方案实施”；已经有实现可选择“只复核”。不强制分成四轮，不用每课重新拼多个MD。各课02已自包含背景、行为合同、案例和交付要求。

网页环境不能直接读取本地项目时，在**学习项目根目录**打包：

```text
python docs/course/tools/course.py pack L00 --project . --output .local/L00-ai-input.zip
```

该包包括本课02和白名单源码，不含整套答案/虚拟环境。敏感内容检查不完备，上传前人工复查；不要上传未获授权的公司源码、客户数据或密钥。

## 7. 什么不应被误认为完成

教材示例跑过，不等于你的应用已实现；标准库机制实验，不等于真实框架、API或服务联调通过；源码地图引用正确，不等于业务正确；Codex完成修改，不等于你已掌握。

本次具体检查见[实际验证报告](validation/report.md)。课程总顺序与预算见[课程导航](01-课程导航.md)。找不到代码时直接查[文件定位与Codex协作](16-文件定位与Codex协作.md)。

### 已有v4错误练习副本，怎样取得本版新测试

不要覆盖`.local/workshops/bug_lab/student.py`，里面可能已有你的答案。先备份个人副本的`.local/workshops/bug_lab/test_bug_lab.py`，再把本版教材只读测试`docs/course/workshops/bug_lab/test_bug_lab.py`复制到该个人测试路径。这样只更新公开题目检查，保留你的实现；新增整数42断言可能变红，这是要补练的差异。已有副本不用再运行`course.py lab`，它会拒绝覆盖。
