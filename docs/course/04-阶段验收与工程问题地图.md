每关预留2小时做考核与整理；功能实现、实验、修复应已在对应课完成。考核失败的补练占复习预算，超出预算就顺延。未运行真实项只能标`blocked`，不能由导师代签通过。

## G1｜L06后：受控只读Agent

交付同一个工作区的解释任务，先调用读取工具再提供文件/行号证据。展示空输入不调用模型、非法工具参数不进入工具、越界路径被拒、循环上限生效和失败日志。临时改变请求或文件名，仍能复现定位流程；说清固定workflow和Agent循环的区别。没有真实API证据时可以通过离线子项，但G1完整状态保持blocked。

## G2｜L12后：修复、测试和独立裁决

在固定`tiny_repo`副本修复分页问题，只允许修改pagination.py。分别展示“测试失败→修复→当前快照通过”；注入零测试、旧报告和越权改文件，验收均拒绝。公开独立入口：

```bash
python -c "import shutil; shutil.copytree('fixtures/tiny_repo', '.local/g2-workspace')"
python docs/course/tools/grade_fixture.py --workspace .local/g2-workspace
```

原始夹具会失败，修复后才应通过。工具从教材受保护位置运行测试，并核对修改范围、收集数和快照，不采信模型自述。它是受控练习裁判，**不是恶意代码沙箱，也不是保密考试**。闭卷过关另换一个未见的边界条件或仓库；不许修改裁判来“修复测试”。

## G3｜L18后：优化可比较，不凭感觉

保留原生和已接入的LangChain路径。用相同任务/种子/资源约束比较至少两个方案，分组统计成功数、成本与延迟，列出无提升或退化样本。先确定指标、后做优化；标注未知费用和失败任务，不把成功子集当全部。给出一个优化ADR：为什么改、怎样测、回退条件是什么。可先用确定性数据验证汇总代码，质量结论必须来自实际任务运行。

## GF｜F06后：真实框架、恢复和审批

真正运行LangChain `create_agent`与LangGraph路径，复用领域工具和G2独立验收，不新建无关机器人。F05在**两个独立进程**完成持久恢复；人为制造“外部动作成功、响应丢失”的窗口，证明通过幂等键/对账避免重复。F06审批绑定tenant、task、patch_hash、base_hash与版本；修改补丁或源版本后旧审批失效。内存检查点成功、模拟重启、标准库状态机都不能替代这些证据。解释中断恢复可能重跑节点头部，不能把写操作随意放在中断之前。[官方中断语义](https://docs.langchain.com/oss/python/langgraph/interrupts)

## GR｜R02后：检索与答案证据

固定语料版本和独立标注题，比较文本、向量、路由和联合/RRF，记录Recall@k及最终引用正确性。手工向量可以检验排序代码，**不能证明真实embedding召回**。用真实嵌入完成单独结果；无答案、权限过滤、过期文件和重复块都要有测试。保存题集、语料hash、配置、逐题结果和失败解释；禁止只展示“联合一定更好”的合成例子。

## G4｜L21后：任务服务与Java联调

启动真实Python任务服务和Java入口，演示tenant隔离、鉴权、过载拒绝、超时/取消与重复提交。数据库唯一约束在并发请求下真实生效，跨进程恢复不依赖内存变量。输出日志用同一trace/task标识串联，指出Java线程、连接池和下游延迟中的实际瓶颈；无法启动数据库/服务就不声称完成联调。L22在此基础上完成陌生题、作品和岗位对照，不新增第七个形式门槛。

## 判定规则

各关按“目标与约束、机制正确、可复现证据、独立变化/诊断、边界诚实”五项各0～2分，课程内部门槛为8/10。越权执行、伪造通过、依赖改裁判取得通过、重复不可逆副作用等关键问题必须先修，不能用其他分数抵消。这是本教材的训练标准，不是行业统一面试标准。
