## 题一：输入边界

```python
def submit(task, client):
    reply = client(task)
    if not task.strip():
        return "invalid"
    return reply
```

task是三个空格，client会扣费。应该移动哪个判断，为什么`None`仍可能报另一种错？

判断要点：先做类型和非空白校验再调用；不是捕获所有异常后统一“模型失败”。能解释Java Controller校验与领域失败的差别即可。补练：自己写is_valid_task，覆盖None、空串、空白、数字和正常字符串，对照L00。

## 题二：可变对象与增量

```python
a = ["read"]
b = a
b.append("test")
```

a是什么？若状态reducer会做old+update，应该返回完整历史还是新事件？

判断要点：a、b引用同一列表；累加reducer应接收新增量，否则重复。不要把Java引用语义与Python赋值想成值复制。补练：创建独立列表并画两种合并结果；对照F04标准库例子。

## 题三：异常类别

客户端可能TimeoutError、ValueError，输入可能本来非法。为何不能一个`except Exception: retry()`解决？

判断要点：非法输入重试无益，结构错误可能是协议/实现bug，外部动作还可能已成功。先按失败层级分类，再谈有限重试与幂等。补练：三个测试各验证一次调用计数与错误码；L00/L01/L10。

## 题四：测试真假

一份报告写exit_code=0、collected=0、success=true，可以接受吗？

判断要点：没有测试不是通过；还要绑定当前代码快照和固定测试集合。补练workshops TestL12，把模型成功声称完全从裁判输入中剥离；L09/L12。

## 题五：看懂一个小diff

原式`start = page_no * page_size`改为`start = (page_no - 1) * page_size`。page_no=1,size=2时两者分别从哪开始？哪些输入仍需验证？

判断要点：下标2与0；page/size需正整数，布尔在Python是int子类要特别判断，列表不能被原地改动。补练固定分页夹具，但L07之后才引入自动写入工作流。
