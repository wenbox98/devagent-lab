**本文件用途：** 先判断本课为何出现、看哪个文件、哪些代码现在存在；不是新增加的一门理论课。

## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** 模型可以接受任务，但尚不能安全读取任意给定路径。

**本课问题：** 为什么看起来以repo开头的路径，仍可能不属于repo？

**期望变化：** 建立工作区归属检查与有界读取；区分无权限、不存在和正常截断。

**不做这一步的风险：** 路径看起来在仓库内，却可能通过兄弟目录前缀、父目录或链接逃出授权范围；模型建议不能替代程序校验。

顺序前置：[L01本课目的](../L01/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[L03](../L03/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 不写文件；PurePosixPath仅演示路径关系，不完成真实符号链接防护。

## 4. 今天先做哪一个动作

只想理解：打开[本课教程](01-教程.md)，先回答“为什么看起来以repo开头的路径，仍可能不属于repo？”。

想改一个输入：按[本课实验的A阶段](03-实验与排错.md)准备副本，**看模块级变量root、good、bad；对比startswith和is_relative_to。** 然后执行：将bad改为/work/repo/sub/a.py；再改回/work/repo2/main.py。只改路径值，不改判断表达式。

已有或准备生成项目代码：把[本课02指令](02-交给AI.md)和当前源码交给Codex，发送“只分析本课意图与实际代码对应，不修改代码”。不必自己猜函数位置，也不必把六份Markdown拼接给它。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 先理解路径解析 | 路径字符串怎样变成真实目标？ |
| 权限与可用性分开 | 有权限与文件存在为何是两项检查？ |
| 控制返回量而不是盲读全部 | 读取大文件时怎样告诉下游还没读完？ |
| 路径授权必须看解析后的目标 | 前缀判断为什么会放过repo2？ |
| 边界检查与隔离是两层能力 | 应用校验为什么不能代替运行环境隔离？ |
| 读取也要有资源预算 | 只读操作为什么也可能耗尽资源？ |

可复制检索词：`pathlib Path resolve is_relative_to symlink workspace`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 给出兄弟目录、../、绝对路径、软链接逃逸四个反例；不能只测正常路径。

要能串起：**不可信path → canonical path → 工作区归属 → 文件类型/大小 → 有界内容。**

具体证据看：三个布尔输出；真实符号链接另在生成的test_l02中验证。
