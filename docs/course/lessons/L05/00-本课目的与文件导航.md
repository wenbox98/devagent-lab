## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** L04能读文件并回答，但同名函数会让第一条搜索命中误导定位。

**本课问题：** 搜索第一名为何不是已经证明的修改位置？

**期望变化：** 分开候选搜索、精读和引用核对，结论能回到当前代码版本。

**不做这一步的风险：** 搜索命中了相似名称就直接修改，Agent可能改到同名但无关的函数；排名只是线索，不是定位正确的证据。

顺序前置：[L04本课目的](../L04/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[L06](../L06/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 本课只定位，不授权写入；purpose字段是人工教学标注。

## 4. 今天先做哪一个动作

只想理解：打开[本课教程](01-教程.md)，先回答“搜索第一名为何不是已经证明的修改位置？”。

想改一个输入：按[本课实验的A阶段](03-实验与排错.md)准备副本，**看模块级hits、candidates及purpose过滤；这里没有名为search_text的函数。** 然后执行：交换hits两项顺序，保留purpose值；再增加一个同名但用途不同的条目。只改该副本列表。

已有或准备生成项目代码：把[本课02指令](02-交给AI.md)和当前源码交给Codex，发送“只分析本课意图与实际代码对应，不修改代码”。不必自己猜函数位置，也不必把六份Markdown拼接给它。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 搜索、阅读和回答是三个动作 | 为何先搜到还必须再读上下文？ |
| 没有匹配是正常事实 | 空匹配与工具异常怎样决定不同下一步？ |
| 把证据作为结构化数据 | 引用最少要保留什么才能核查？ |
| 检索结果是候选证据，不是结论 | 什么候选命中并不能支持当前结论？ |
| 召回与精确度解决不同失败 | 正确文件没召回和选错文件分别怎么诊断？ |
| 引用必须可回到原始文件 | 文件改动以后旧行号还能证明什么？ |

可复制检索词：`code search retrieval precision recall source citation`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 加入reporting.py同名函数；只改搜索排序，不改测试。观察Agent是否错误地把排名当事实。

要能串起：**query → text/symbol matches → 精读范围 → path/lines/hash → 可核对引用。**

具体证据看：候选路径及空匹配返回；真实项目需读取函数和契约而不是依赖purpose标签。
