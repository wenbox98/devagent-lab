## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** R01有多条检索路径，但单路会漏召回，多路又增加成本和噪声。

**本课问题：** 这次应该选一路，还是合并多路，怎样证明多出的复杂度值得？

**期望变化：** 分清路由、融合和重排，按合法候选名次融合并做任务分组对照。

**不做这一步的风险：** 不同检索器的分数被直接相加、重复文档多次投票或一路不可用未被记录，融合排名看似更丰富却无法解释或评估。

顺序前置：[R01本课目的](../R01/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[L19](../L19/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 预设semantic_fixture不是语义模型测量；融合第一名不等于有答案。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 一、先给“策略检索”一个本课程的明确含义 | 路由和融合分别解决哪一个决策？ |
| 二、联合检索不是把两个原始分数相加 | 两个不同尺度的原始分数为什么不能直接混算？ |
| 三、过滤、融合和重排的顺序有安全含义 | 何时过滤才能保证未授权内容不被暴露？ |
| 四、与L13的A/B工具选择做同构迁移 | L13的工具资格思想怎样迁移到检索器？ |
| 五、一份足以指导工程决策的对照实验 | 哪几组任务能暴露融合增加的噪声或成本？ |
| 六、本课产出要能拿去复盘和面试 | 实验报告需要哪些原始记录才能复查？ |

可复制检索词：`hybrid search RRF reciprocal rank fusion rerank ablation`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 用手算数据构造重复命中和一路不可用；然后做route、hybrid、route_then_hybrid的消融比较。

要能串起：**route或多路召回 → 各路去重 → RRF按名次融合 → 可选reranker → 截断上下文。**

具体证据看：每路去重后的名次、权限过滤和最终得分；检查同一路重复不重复计票。
