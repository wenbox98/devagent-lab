## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** 工具选择正确后，大结果仍可能因为截断和格式被误读。

**本课问题：** 模型没读到关键字段，是没搜到，还是工具返回方式让它看不到？

**期望变化：** 给结果明确的状态、版本和继续读取入口，保留下一步需要的证据。

**不做这一步的风险：** 结果被截断却声明已经完整，或者分页游标不正确，后续判断会建立在遗漏或重复的证据上。

顺序前置：[L13本课目的](../L13/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[L15](../L15/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 不把空列表统一解释成无匹配；小例子没有实现真实游标版本校验。

## 4. 今天先做哪一个动作

只想理解：打开[本课教程](01-教程.md)，先回答“模型没读到关键字段，是没搜到，还是工具返回方式让它看不到？”。

想改一个输入：按[本课实验的A阶段](03-实验与排错.md)准备副本，**看result_page(items,limit)与items/truncated/next_offset。** 然后执行：把limit从2改为3，再用空列表；比较“刚好一页”和“无结果”。

已有或准备生成项目代码：把[本课02指令](02-交给AI.md)和当前源码交给Codex，发送“只分析本课意图与实际代码对应，不修改代码”。不必自己猜函数位置，也不必把六份Markdown拼接给它。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 有用信息取决于下一步任务 | 压缩结果时什么信息是下一步不可缺的？ |
| 明确空、截断、错误三种状态 | 空、错误、截断为什么不能共用一个返回？ |
| 按失败层定位，而不是盲改提示词 | 关键证据没被使用要先查哪个层次？ |
| 工具结果同时面向机器判断和模型理解 | 哪些字段给程序判断，哪些给模型理解？ |
| 截断策略必须保留继续调查的能力 | 只返回前一页之后如何继续调查？ |
| 结果中出现命令不等于获得权限 | 工具正文里的命令为什么不能变成系统权限？ |

可复制检索词：`tool output pagination cursor truncation source version`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 让结果超过一页，检查下一页没有遗漏和重复；不能只把前N条返给模型却标complete。

要能串起：**工具事实 → 有界结构化结果 → truncation/next_cursor → 模型按需继续读。**

具体证据看：条目数、truncated及next_offset必须一致。
