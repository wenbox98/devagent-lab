## 原教程独立练习

题目：分别为等待执行和正在执行设置超时，说明它们记录在哪一层。

提示：排队超时没有启动进程，执行超时已经有进程需要清理。

## 代码地图预测题：目标契约与反事实

**题目：** communicate(timeout=1)超时后，只抛异常不清理，会留下什么？

**参考判断：** 可能留下仍在运行的进程和后代。等待超时不等于工作已停止；需要记录实际清理结果。输出上限必须在读取时实施，而不是先收集全部输出再截断。

**反事实核对：** 在自有练习环境启动短时受控子进程和大输出，验证超时/截断/终止；不是运行任意未知仓库。

**远迁移方向：** Java Future超时和下游HTTP请求被取消是一回事吗？给出资源仍占用的证据。

评分：只说名词0分；能说机制1分；能预测具体分支且给出反例2分。还必须有独立修改和失败证据；这个分数不是就业预测。允许有不同实现，但不得跳过安全/事实边界。
