**本文件用途：** 先判断本课为何出现、看哪个文件、哪些代码现在存在；不是新增加的一门理论课。

## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** 修复可重试，但无变化地重复同一操作会消耗预算。

**本课问题：** 什么变化是有用的进展，什么只是把同一次失败再说一遍？

**期望变化：** 用执行事实与新证据判断进展，和硬预算共同决定停止。

**不做这一步的风险：** 模型每次换一种说法但实际动作毫无进展，循环仍继续耗费预算，重复修改或测试却没有新增证据。

顺序前置：[L10本课目的](../L10/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[L12](../L12/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 不根据模型换了措辞判定进展；停止不等于任务成功。

## 4. 今天先做哪一个动作

只想理解：打开[本课教程](01-教程.md)，先回答“什么变化是有用的进展，什么只是把同一次失败再说一遍？”。

想改一个输入：按[本课实验的A阶段](03-实验与排错.md)准备副本，**看recent、events、repeated，重点看deque长度和set大小。** 然后执行：将events最后一项改为("read","new-evidence")，只变观察值。

已有或准备生成项目代码：把[本课02指令](02-交给AI.md)和当前源码交给Codex，发送“只分析本课意图与实际代码对应，不修改代码”。不必自己猜函数位置，也不必把六份Markdown拼接给它。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 先定义什么叫进展 | 进展需要新增哪类可观察事实？ |
| 重复检测与硬预算配合 | 重复阈值和硬预算各补哪个漏洞？ |
| 提前停止也有错误成本 | 过早停止会损失哪种正常探索？ |
| 进展应依据状态变化而不是文字变化 | 模型改变描述但状态没变算不算进展？ |
| 预算有多个维度 | 步数、耗时、费用为什么要分开限额？ |
| 停止与降级同样需要质量标准 | 停止时怎样报告未完成而非伪装成功？ |

可复制检索词：`no progress fingerprint bounded retry agent budget`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 改变模型措辞却保持工具参数和文件hash不变，检测重复循环。

要能串起：**状态指纹/新证据 → 比较前一轮 → 是否有进展 → 继续/改变策略/停止。**

具体证据看：最后一轮stop还是continue；主项目指纹来源必须是实际事实。

在`docs/learning-records/L11.md`分别填写概念观察、实际实现、独立修改和未验证项。源码地图由Codex基于实际源码填写；个人理解由你填写。标准库示例、框架离线运行、真实API、完整服务是不同验证层次。
