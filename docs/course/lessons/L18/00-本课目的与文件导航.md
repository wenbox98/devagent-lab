## 1. 为什么现在学这一课

**当前条件（不是对你进度的断言）：** L17可以比较策略，但反复对熟悉题调参会污染改进证据。

**本课问题：** 升级的收益是真改善、偶然波动，还是只对看过的题有效？

**期望变化：** 按任务快照划分调优/保留集，保留所有尝试并报告分组退化。

**不做这一步的风险：** 一次修改让总平均分提高，却让某组任务或安全边界变差；没有固定对照和失败轨迹就无法定位回归。

顺序前置：[L17本课目的](../L17/00-本课目的与文件导航.md)。前置是能力条件，不是“看过文档”即可；由Codex核对现有源码/测试。 后续[F03](../F03/00-本课目的与文件导航.md)继续使用本课产物。

**本课不负责：** 合成runs不是模型实测；看过的留出题不再提供同等独立证据。

## 4. 今天先做哪一个动作

只想理解：打开[本课教程](01-教程.md)，先回答“升级的收益是真改善、偶然波动，还是只对看过的题有效？”。

想改一个输入：按[本课实验的A阶段](03-实验与排错.md)准备副本，**看runs中old/new的text/symbol分组及分母len(v)。** 然后执行：让new.symbol多一个失败样本，保持text不变；比较分组分母和总体。

已有或准备生成项目代码：把[本课02指令](02-交给AI.md)和当前源码交给Codex，发送“只分析本课意图与实际代码对应，不修改代码”。不必自己猜函数位置，也不必把六份Markdown拼接给它。

## 5. 读不懂时，带着什么目的查资料

下列问题与[教程](01-教程.md)的知识段一一对应。查到能回答该问题、能指出观察证据即可先回到实验，不要求把官方站点读完。

| 本课知识段 | 为什么讲：你要解决的具体问题 |
| --- | --- |
| 任务、尝试、评分器各是什么 | 任务、一次尝试和评分器分别负责什么？ |
| 分开调优与保留样本 | 看过的保留集还能提供怎样的证据？ |
| 升级也要保护旧能力 | 新能力提升时怎样发现旧能力退化？ |
| 实验的最小单位是任务快照与一次尝试 | 仓库不重置会怎样污染下一次尝试？ |
| 分组结果比总体数字更接近工程决策 | 总分上升为什么可能掩盖某组下降？ |
| 评测集本身会被污染 | 反复用评测题调参会改变什么结论？ |

可复制检索词：`agent evaluation heldout repeated trials dataset leakage`。优先使用[本课教程末尾的官方参考](01-教程.md)和[官方阅读路线](../../09-技术版本与官方阅读路径.md)。这些链接沿用已有教材来源；本轮聚焦结构与指代，未重新核验所有网页或依赖版本。

## 6. 本课完成后要留下什么

**项目阶段怎样证明风险已被处理：** 构造一个总分升高但某组退化的报告；保留失败轨迹并设置安全回归阻断。

要能串起：**任务划分 → 固定版本/预算 → 重复运行 → 独立grader → 分组差异 → 升级/回滚决定。**

具体证据看：成功数/尝试数、分组变化和任务来源；不能只展示提升的一组。

在`docs/learning-records/L18.md`分别填写概念观察、实际实现、独立修改和未验证项。源码地图由Codex基于实际源码填写；个人理解由你填写。标准库示例、框架离线运行、真实API、完整服务是不同验证层次。
