## A. 不等项目生成，也能先做的概念实验

**执行目录统一为：学习项目根目录（能同时看到 `devagent/` 和 `docs/course/` 的目录）。** 尚未建项目时，先看[从这里开始](../../00-从这里开始.md)初始化步骤。以下命令中的`python`应指向你的Python环境；不是让你安装一个叫devagent的第三方包。

先创建本课副本（已有副本时工具会拒绝覆盖，不会丢掉你的改动）：

```text
python docs/course/tools/prepare_example.py R01 --project .
```

基准只读文件：[docs/course/lessons/R01/00-example.py](00-example.py)。本阶段**只改**`.local/concepts/R01/00-example.py`，不改`docs/course/`、公共裁判或项目主实现。

**具体看哪里：** tokens(text)、bm25(query,docs)与main中的docs和ranking。

**具体改什么：** 把查询换成quantum，再给docs加入包含该词的文档；先比较空召回与新增索引内容带来的命中。

**为什么做：** 外挂知识库的内容怎样进入回答，为什么有相似分数还不足以证明答案？

**观察什么：** 文档ID、原文、来源版本和召回；真实向量排名须另行记录。

运行未改副本留基线，再修改指定输入运行同一命令：

```text
python .local/concepts/R01/00-example.py
```

## 3. 实现后运行这些案例

**下列应用命令需要AI按02生成入口后才存在；不是本压缩包已交付的应用。**

```bash
python -m devagent.demos.r01 --case normal
python -m devagent.demos.r01 --case stale_index
python -m devagent.demos.r01 --case no_answer
python -m unittest discover -s tests -v
```

| 案例 | 验收要看什么 |
| --- | --- |
| `normal` | 候选包含可回溯来源和当前版本 |
| `stale_index` | 当前代码任务不能静默使用旧版本证据 |
| `no_answer` | 没有足够证据时不强行报告找到答案 |

每个案例保留输入、实际结果、关键事件、测试数量和代码版本。先复现失败，再修改；修复后同时运行本课与前置回归。结果不符时先检查输入/状态与调用边界，不先换模型。
