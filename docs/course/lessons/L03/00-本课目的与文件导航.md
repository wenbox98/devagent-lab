## 现在只需要知道什么

这一课开始把模型“说的话”变成可被程序执行的工具请求。L02 已经有受控文件工具，L03 给它加稳定的调用协议。模型只提出工具名和参数，真正的权限仍由执行代码判断。

你会第一次看到 Agent 的动作接口，但不是让 Python 执行模型生成的任意字符串。成品是一个工具调度器：接收 ToolCall，返回与之关联的 ToolResult。

**基线状态：** 本课应用增量尚未在固定基线中实现；教材例子与目标接口不能冒充当前应用。

## 本课选择与边界

| 具体问题 | 本课基础方案 | 怎样验收 | 没有覆盖什么 |
|---|---|---|---|
| 工具选择 | 固定注册表，不动态eval/import | unknown_tool 时handler次数0 | 新工具只能由程序注册 |
| 参数 | 结构校验后进入原L02工具 | 坏类型拒绝、合法类型越界仍拒绝 | schema不是权限系统 |
| 关联 | 请求与结果保留call_id | 多调用和拒绝都有正确ID | 不等于跨进程幂等 |
| 模型适配 | 增加工具提议的领域表达，Fake同步升级 | 工具提议不误判空文本 | 单纯兼容HTTP地址不足以证明模型支持 |
