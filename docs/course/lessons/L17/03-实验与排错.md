## A. 不等项目生成，也能先做的概念实验

**执行目录统一为：学习项目根目录（能同时看到 `devagent/` 和 `docs/course/` 的目录）。** 尚未建项目时，先看[从这里开始](../../00-从这里开始.md)初始化步骤。以下命令中的`python`应指向你的Python环境；不是让你安装一个叫devagent的第三方包。

先创建本课副本（已有副本时工具会拒绝覆盖，不会丢掉你的改动）：

```text
python docs/course/tools/prepare_example.py L17 --project .
```

基准只读文件：[docs/course/lessons/L17/00-example.py](00-example.py)。本阶段**只改**`.local/concepts/L17/00-example.py`，不改`docs/course/`、公共裁判或项目主实现。

**具体看哪里：** strategies字典、sum(calls)和len(calls)。

**具体改什么：** 把small的调用次数从5改为2；保持单次教学成本0.02，比较整任务合计。

**为什么做：** 我究竟在优化一条请求，还是用户真正要完成的整个任务？

**观察什么：** 总额、次数和成功条件；单次便宜不保证整任务更便宜。

运行未改副本留基线，再修改指定输入运行同一命令：

```text
python .local/concepts/L17/00-example.py
```

## 三次回忆检查

当天关掉教程，回答：为什么单次便宜不代表任务便宜？哪些延迟适合并行优化？缓存键缺什么可能越权？

第3天只看题目复做这个变体；第7天把同一机制迁移到另一种资源或失败情境。每次10分钟以内先作答再翻资料，把未答出的因果环节记到学习记录。日期按实际完成日计算，不要求启动自动提醒。

**通过条件：** 功能测试成立，能解释一个错误实现为何失败，独立变体有自己的修改与Git diff。读懂答案或看到AI运行成功不等于通过。前两项未通过则补练，不继续堆新功能。
