## 3. 整数42的核验，不再混淆三个对象

对`.local/concepts/L00/00-example.py::handle`运行探针：整数42真实结果是`AttributeError`且`client_calls=0`；字符串42真实结果是`succeeded`且`client_calls=1`。这是原始概念代码直接调用strip的行为，不是它已经实现规范拒绝。

对错误练习副本，新增公开测试`TestL00.test_integer_task_is_rejected_before_client`要求`invalid_input`且客户端零调用。参考实现满足该目标，学生初始实现不满足。项目起始骨架的`run_task`仍抛`NotImplementedError`，本轮没有暗中替用户完成应用。

## 5. 不覆盖学习成果的边界

副本创建遇到已有目标会拒绝覆盖，符号链接目标会拒绝跟随。源码清单用AST读取Python符号，不导入或执行应用；源码地图遇到未知符号、旧哈希、缺少职责或planned条目，不会显示为完整有效。

探针会执行你信任的本地概念副本，公开裁判也会运行受控教学代码；它们不是运行不可信仓库的安全沙箱。源码打包仍需人工检查敏感数据，正则检测不是完整保密保证。
