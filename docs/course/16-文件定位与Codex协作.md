## 为什么需要这一页

教材可以确定已经提供的概念代码，却不能预知Codex会把你的实际项目拆成哪些函数。把“建议结构”写成“已经存在”会让学习者四处找不存在的文件。本版用三种状态明确区分：已提供的教材基准、准备后存在的练习副本、需要从实际源码映射的项目位置。

## 路径到底相对什么

| 看到的路径 | 它的根目录与状态 |
| --- | --- |
| `lessons/L00/01-教程.md` | 教材根目录的文件；阅读器链接可直接打开 |
| `docs/course/lessons/L00/01-教程.md` | 教材复制到学习项目以后的同一文件 |
| `.local/concepts/L00/00-example.py` | 学习项目里的个人概念副本；用prepare_example创建 |
| `.local/workshops/bug_lab/student.py` | 学习项目里的八类错误练习副本；用course.py lab创建 |
| `devagent/app.py` | 你的应用源码；L00初始化骨架存在但尚未实现，后续才逐课形成 |
| `docs/learning-records/L00-code-map.json` | 实施后由Codex依据真实源码生成；不是教材预先知道的地图 |

同名`app.py`不能不带前缀使用。所有课内运行命令默认在学习项目根目录执行；Java与SQL的额外条件在对应实验页明确标注。

## 三种Codex模式

`ANALYZE_ONLY`：只读仓库，回复目的、真实文件与缺失项。不写文件、不安装依赖、不运行应用。默认使用它，适合你不确定教材在让你做什么时。

`IMPLEMENT`：用户明确要求后，只做本课基础增量与已列故障路径，运行实际可运行的测试，交付源码地图与证据。独立题留给学习者，不自动提交Git。

`REVIEW_ONLY`：读取现有实现与本课合同，列偏差，不改代码。是否执行测试由用户另外明确；不能把“只读分析”当作自动获准运行所有项目脚本。

每课`02-交给AI.md`已包含以上流程及本课具体意图，无需把本文件再作为附件。

## 我不知道看哪个文件时，Codex应该交回什么

| 职责 | 必须给的内容 | 不允许的替代 |
| --- | --- | --- |
| 入口 | 实际文件、函数/HTTP路由/测试入口、输入 | “看入口层” |
| 输入边界 | 第一个相关判断、输入来源、失败出口 | 只说“加校验” |
| 核心决策 | 当前代码怎样实现本课目的 | 复制教程理想行为冒充当前行为 |
| 下游/状态 | 具体调用、写入或状态前后值 | 只看成功文字 |
| 测试 | 实际测试方法、断言与收集数 | “测试都过了”但没有运行 |

尚未生成时，Codex应给“需要寻找哪种职责、预期输入输出、建议落点”，把实际函数留空。已有项目命名不同可以复用，不需要迁移到教材建议名称。

## 源码地图：引用可检查，语义仍要验证

地图格式见[模板](templates/code-map.json)。五种标准role是`入口`、`输入边界`、`核心决策`、`下游/状态`、`测试`；可以多条记录指向同一文件中的不同位置。`observed`条目必须有实际相对路径、symbol、anchor原文和从文件字节算出的sha256。`planned`或`missing`不计为完成。

在学习项目根目录运行：

```text
python docs/course/tools/code_map.py inventory --project .
python docs/course/tools/code_map.py validate --project . --map docs/learning-records/L00-code-map.json
```

`inventory`只扫描受控源码目录，列真实路径与Python定义，不猜职责，不导入项目代码。`validate`检查文件存在、符号或配置键、原文锚点及当前哈希；源码变化后会提示地图过期。它不判业务实现、权限策略或学习能力是否正确；Java/SQL只做文本定位，不声称语法或编译验证。

映射校验不是必做的额外作业。你可以先让Codex在回复中给清楚的文件与代码片段；需要持久记录时才在实施模式保存JSON。不要为了填表拖慢一段本来已看懂的代码。

## 已有八类练习怎么定位

创建方式和每课对应函数、测试类、工作目录见[错误练习说明](workshops/README.md)。只在副本`student.py`修改当前函数，不修改公共测试。

L00的42通过[探针脚本](tools/probe_l00.py)调用副本中真实的`handle`。它不是调用`starter/devagent/app.py::run_task`，也不能证明你的已生成项目已经实现正确拒绝。其他课在各自03/05写明要看的函数或模块级变量。

## 找资料时保留目的

先从当前课00页拿一个具体问题，再查01相应知识段或官方阅读入口。把查询写成“我要保证哪一层的什么行为”，而不只是搜索技术名。读到能预测一个具体输入、知道该观察什么证据后，回到实验。

本版沿用v4官方来源，未把所有外部网页重新核验一遍，也未升级依赖基线。涉及API和框架签名时，以你实际安装版本和官方资料核对；缺环境诚实标blocked。
