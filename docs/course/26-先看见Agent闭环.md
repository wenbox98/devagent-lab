# 先看见Agent闭环：可选预览，不算提前过关

已经觉得“全在学Python和经典工程”时，可先运行这个受控实验：

```bash
python docs/course/lessons/L04/01-mechanism.py
```

它用脚本模型提出read_file提议，真实读取自己创建的临时文件，将结果放进下一轮消息，再根据该内容生成答案。没有调用大模型/公网，没有修改主项目，也没有执行仓库代码。

先观察events中的tool提议、真实observed内容与第二轮final。把临时文件内容改变会影响最后answer；这就是反馈进入下一步的外部证据，不需要读取隐藏推理。

这不证明模型能自主选工具，也不代替L03/L04完整实现。它只让你先看到近期目标：L02做好受控读取，L03给工具加协议，L04把反馈闭环连接起来。

当前仍从L02真实read_file继续，不要求回头重读全部Python基础。等进入L04，再比较这个小实验与真实项目的预算、错误、消息和工具接口有哪些差距。
