# 课程导航｜34课，32周，320小时预算

[从这里开始](00-从这里开始.md)

**每周10小时是暂定排期假设，不是你已经承诺的时间。** 244小时课内学习+12小时阶段验收+64小时复习=320小时。投入变化时整体延长；不删除独立练习维持假进度。已有代码按同一仓库迁移，不从零重做。

本版v4.2.0已将34课全部改为先读目的和文件导航；本轮没有新增课程或暗增预算。先原生闭环，再在L12后学习F01/F02；保留同一工具、安全边界和独立grader，后面继续优化并加入LangGraph和RAG。

## 不需要为了“主流”继续堆组件

多Agent、模型训练、复杂分布式平台不列为本主线必修。MCP等在真实岗位/项目要求出现时扩展，不能替代已要求的LangChain、LangGraph、RAG、安全执行和Java联调。最终输出是可解释且有证据的作品，不是生产级安全平台保证。
