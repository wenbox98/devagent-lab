## 实现事实

- 主链路：结构化 search_text 提议 → registry 实际搜索 → 候选 ToolResult 进入下一次 complete → read_file → 同次快照内容和 source_hash → 程序保存 Citation 证据 → 模型选择引用 → 来源及当前版本校验 → answered。
- `tools/files.py::_read_snapshot` 复用原 L02 的 canonical root/path、归属、类型、大小、UTF-8/控制字符检查。一次打开，最多读取 max_bytes+1；同一 raw bytes 计算全文件 SHA-256 和解码文本。`read_file` 从快照取行窗口，默认 50 行、inclusive end_line、truncated/next_start_line 不变。FileReadResult 末尾新增默认 None 的 source_hash，旧位置构造兼容；真实 read 总会返回 hash，list_files 的 size_bytes 仍为全文件 stat 大小。
- `tools/search.py::search_text(root, query, include_globs=None, max_results=20)` 为区分大小写的逐行字面匹配，返回 matches（path/1-based line/snippet）、truncated、scanned_files。搜索直接扫描安全快照全文，不使用 read_file 的 50 行返回窗口。
- 宿主固定上限：单文件 65536 字节、128 个文件读取尝试、2048 个目录项、32 层目录。内容读取总量至多 128×65537 字节（包含超限判断空间）。模型不能修改这些预算或 workspace。max_results 默认 20，允许 1..100 的非 bool 正整数；达到结果上限就保守标 truncated=True，即使恰好只有这些匹配。遍历预算截断也显式标记，绝不宣称完整扫描。
- 查询最多 256 字符；include_globs 至多 16 条、每条 256 字符。`*.py` 匹配任意层级 basename；`src/**/*.py` 支持 ** 的零层或多层目录。相对 glob 只缩小权限范围，拒绝绝对路径、..、反斜杠、盘符和空路径段。使用文件系统枚举顺序，无排名或持久 cursor。
- 搜索跳过隐藏目录/文件、所有 symlink/junction 和不允许后缀；沿用 L02 拒绝超大、解码失败和二进制内容。不支持内容不算候选；权限、消失文件、I/O 失败返回真实失败，不变成空匹配。no-match 是 ok=True、matches=[]；仅未碰到预算上限时 truncated=False。
- `agent/citations.py::Citation` 保存 source_path/start_line/end_line/content/source_hash。validate_citation 校验 workspace 与文件类型、路径为 canonical 相对路径、有效行号、当前全文件 hash 和精确片段内容；版本变化返回 stale_evidence，非法行/内容返回 invalid_citation；不偷偷更新旧引用。
- ModelResponse.citations 是候选引用；AgentState.evidence 只从本对话成功 read_file 结果装配，最终 citations 必须精确匹配已读窗口后再校验当前文件。空文件/EOF 外的空窗口不产生引用。search 结果、模型凭空填写或篡改内容的 Citation 均不能变成有效最终引用。可返回多个真实引用；不自动证明回答论断在语义上正确。
- run_task/RunResult 仍是旧单次请求接口，不承担工具引用；新引用输出落在 AgentState。waiting/resume 保留实际读证据并在恢复后最终回答时重新校验；双预算、ToolError 和 metadata 规则不变。
- Registry 固定集合恰好为 read_file/list_files/search_text。原 L03 两处测试按合法能力增量更新固定集合和 search 必填 query，保留未知工具、宿主权限、metadata 过滤及真实 handler 断言；没有删除测试或迁就错误实现。
